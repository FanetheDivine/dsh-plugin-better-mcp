# 数据模型：Spec Kit 访谈与审查记录

## 待确认决策

| 字段 | 含义 |
| --- | --- |
| 稳定编号 | 跨访谈批次保持不变的决策标识 |
| 问题 | 需要用户确认的需求或实现选择 |
| 推荐答案 | Agent 根据探索结果给出的首选方案 |
| 理由 | 推荐答案的依据 |
| 依赖 | 回答当前问题前必须确定的其他决策编号 |
| 状态 | `not asked`、`asked`、`answered`、`skipped` 或 `waived` |

已回答项从待确认列表移入澄清记录。跳过项保持可见，访谈豁免覆盖全部剩余未确认事项及风险。

## 文档状态

| 状态 | 含义 | 允许的下游阶段 |
| --- | --- | --- |
| `Draft` | 当前完整文档未获批准或豁免 | 当前文档的探索、访谈与审查 |
| `Approved` | 用户明确批准当前完整文档 | 下一 Spec Kit 阶段 |
| `Waived` | 用户明确豁免审查并接受记录的风险 | 下一 Spec Kit 阶段 |

实质修改使状态回到 `Draft`。纯排版修正保留当前状态。

## 澄清记录

每条记录包含会话日期、稳定编号、问题与最终答案。新答案取代旧答案时，关联决策与受影响文档同步更新。

## 审查记录

每条记录包含日期、决定、当前完整文档范围、未确认事项与风险。历史记录持续保留，最新记录对当前版本生效。

## 受管文件摘要

integration manifest 以仓库相对路径为键，以文件内容的 SHA-256 为值。修改受管 skill 或模板后，对应摘要必须与实际文件一致。
