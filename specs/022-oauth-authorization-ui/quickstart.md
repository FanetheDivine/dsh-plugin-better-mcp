# Quickstart: OAuth 授权与待授权提示

## 准备

1. 在仓库根目录运行 `pnpm install`。
2. 运行 `pnpm full-check`，确认类型、代码质量、单元与产物测试通过。
3. 在已安装本插件的 DSH Desktop 中刷新或重新加载插件。

## 验证 Figma

1. 使用 README 推荐配置添加 `https://mcp.figma.com/mcp`。
2. 在已配置的 MCP 面板确认 Figma 显示待授权与高亮授权链接。
3. 点击授权，确认 DSH 使用默认浏览器打开 Figma 授权页，且不出现客户端不存在错误。
4. 完成 Figma 授权，确认页面提示授权完成。
5. 返回面板，确认 Figma 变为已授权并连接，侧边栏待授权动效停止。

## 验证直接链接行为

1. 右键配置面板中的授权链接，确认可见标准链接的目标地址与在新标签页打开命令。
2. 使用 Tab 聚焦链接并按 Enter，确认可完成授权导航。
3. 检查浏览器授权地址来自 `/better-mcp/oauth/start` 的重定向。

## 验证侧边栏提示

1. 配置至少一台待授权 OAuth 服务器，确认侧边栏图标高亮并出现阴影呼吸动效。
2. 完成该服务器授权，确认动效在状态刷新后停止。
3. 全部服务器已授权时，确认图标保持常规样式。
4. 开启系统减少动态效果偏好，确认图标仍高亮但没有持续呼吸。

## 验证会话目录

1. 配置一台未授权 OAuth 服务器，触发会话第一步，确认目录提醒不包含该服务器。
2. 完成授权，确认在线 Agent 立即收到包含该服务器的新目录提醒。
3. 退出登录并进入后续步骤，确认服务器从新目录中移除。
4. 配置 stdio / `auth: none` 服务器，确认目录显示规则不变。

## 回归验证

- stdio 与 `auth: none` 服务器不显示授权入口，也不触发待授权提示。
- 删除待授权服务器后提示停止。
- 多服务器只完成部分授权时，提示保持。
- 授权启动失败时显示原始错误，用户可再次点击链接。
