# Data Model: MCP 状态与会话同步

## 服务器状态快照

沿用现有 `PanelSnapshot` 与 `ServerRow`。

| 字段 | 规则 |
| --- | --- |
| `name` | 服务器唯一名称 |
| `state` | 当前连接状态 |
| `toolCount` | 连接成功时可提供 |
| `connectedAt` | 连接成功时可提供 |
| `attempt` / `maxAttempts` | 连接或重连时可提供 |
| `error` / `cleanup` | 失败或清理异常时可提供 |

快照按面板实例临时保存。每次读取或操作结果携带客户端序号，只有最新序号能替换当前快照。面板卸载后序号失效。

## 会话目录消息

沿用现有 `CatalogSource` 与 user 角色消息。

| 字段 | 规则 |
| --- | --- |
| `kind` / `form` | 固定标识本插件目录 |
| `update` | 更新消息为 `true` |
| `entries` | 按名称排序的完整目录，每项包含名称、简介与可见性 |
| `overrides` | 当前会话的显式可见性选择 |

目录正文由 `<system-reminder>` 包裹。消息先进入 Agent 的下一步队列，步骤准入后进入会话消息日志。目录投影继续折叠已准入的消息。

## 待处理目录

待处理目录是 Agent 下一步队列中带有本插件来源标识的消息。

- 注入前以最后一条待处理目录参与去重。
- 同一步出现多条目录时，只保留最新目录。
- 待处理目录被步骤准入或取消后，以会话日志中的投影为准。

## 状态流转

```text
面板挂载 → 立即读取 → 等待 1 秒 → 串行刷新
面板卸载 → 停止计时 → 忽略在途结果

配置对账完成 → 重算工具限制 → 在线会话注入目录
可见性变化 → 重算调用方限制 → 调用方注入目录
下一步准入 → 合并旧目录 → 提交最新目录 → 更新目录投影
```
