# Quickstart

## 自动检查

```sh
pnpm install
pnpm format
pnpm check
pnpm build
```

核对快照、表单、字典、静态渲染与打包测试全部通过。

## 实机验证

1. 在真实 DSH 宿主安装本分支构建并打开 Web GUI。
2. 点击侧栏 MCP 图标，确认入口无文字，悬停显示「MCP 服务器」；宽窄栏切换时保持 36×36 紧凑 entry 布局。
3. 确认点击后直接进入 `better-mcp` 行配置页，不出现 MCP 弹窗，包详情页也不重复显示面板；面板标题为「已配置的 MCP」，只有「新增 MCP」，没有「刷新」。
4. 确认服务器行没有名称图标与来源标签；其他来源的服务器不出现在列表。
5. 打开「新增 MCP」，确认默认选中 stdio 且 stdio 位于传输方式首位。
6. 切换到 HTTP，确认没有认证方式和回调地址字段，授权范围仍在。
7. 聚焦「OAuth 客户端标识」，确认显示 DSH 与 Codex；选择 Codex 后输入框填入其公开标识，改回 DSH 后清空。备选项打开前后，表单弹窗均不出现整体纵向滚动条。
8. 在输入框输入自定义标识，确认备选项不会覆盖输入。
9. 悬停并用键盘聚焦标签右侧问号，确认出现 Figma 示例说明。
10. 保存配置并观察状态自动更新；触发一次读取失败，确认仍有重试入口。
11. 切换中英文，核对新增文案与备选项说明。
12. 打开「编辑 MCP 服务器」，确认关闭图标位于标题栏最右侧。
13. 确认列表底部不显示固定的懒加载说明，懒加载开关仍有悬停提示。
14. 确认「待授权」徽标使用醒目的警告色、边框与字重，「已授权」保持普通样式。
15. 确认「已配置的 MCP」为 18px / 600，服务器名称为 16px / 600。
