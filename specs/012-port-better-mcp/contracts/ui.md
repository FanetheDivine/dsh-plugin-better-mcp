# Contract: Web UI

## 槽位

| 槽位 | 注册参数 | 用途 |
| --- | --- | --- |
| `sidebar.footer.action` | `{ name, id: 'better-mcp', order: 52, locale: NS }` | 侧栏底部 MCP 图标，点开弹窗面板 |
| `plugins.row.config` | `{ name, key: 'dsh-plugin-better-mcp#better-mcp', locale: NS }` | “插件”页本行配置页 |

客户端入口 `inject` 为 `['slots', 'locale']`。字典命名空间 `dsh-plugin-better-mcp`，包含 `zh` 与 `en`。

## 共享面板

侧栏弹窗与配置页使用同一个 `McpPanel` 组件；操作与数据完全一致。

### 头部

- MCP 图标、标题“MCP 连接 / MCP connections”。
- “新增服务器”按钮。
- “重试”按钮与关闭按钮 `×`（仅弹窗视图显示关闭）。

### 服务器列表

每行：

| 元素 | 内容 |
| --- | --- |
| 状态点 | `connected` 绿、`connecting`/`reconnecting`/`waiting-credentials` 橙、`failed` 红、其余灰 |
| 名称 | 服务器名 |
| 归属标记 | 本插件 / 外部 |
| 授权标记 | `auth=oauth` 时显示“已授权 / 待授权” |
| 懒加载开关 | 仅本插件服务器；关闭即挂载，打开即卸载 |
| 状态文字 | 状态名与说明；连接成功显示工具数 |
| 地址 | `streamable-http` 服务器显示 URL |
| 操作 | 重连；授权 / 重新授权 / 退出登录；编辑；删除 |

- 外部服务器只显示状态，不显示开关与增删改按钮。
- 操作进行中该行按钮禁用并显示 `…`。
- 空列表显示“还没有 MCP 服务器。”

### 新增 / 编辑表单

字段：

| 字段 | 控件 | 校验 |
| --- | --- | --- |
| 名称 | 文本 | 新增时可编辑；`^[A-Za-z0-9_-]{1,32}$`，重名拒绝 |
| 传输 | 单选 | `streamable-http` 或 `stdio` |
| 地址 | 文本 | http 必填，绝对 URL |
| 请求头 | 多行 `Key: Value` | 仅 http |
| 命令 | 文本 | stdio 必填 |
| 参数 | 每行一个 | 仅 stdio |
| 认证 | 单选 | OAuth 或无 |
| 懒加载 | 开关 | 默认开 |
| OAuth 客户端标识 | 文本 | 可选 |
| OAuth 客户端密钥 | 密码 | 可选；只提交给宿主，不回显 |
| OAuth 回调地址 | 文本 | 可选；回环地址 |
| Scopes | 空白分隔 | 可选 |

- 编辑时名称只读；保存走“更新”，删除走“删除”。
- 保存成功后关闭表单并刷新快照；失败时保留输入并显示原因。
- 传输方式切换时清空不适用的字段。

### 聚合端点区

- 每组一行：地址（等宽字体）、标题、复制按钮。
- 令牌行：掩码显示、显示/隐藏、复制、轮换。
- 复制成功 1.5 秒内按钮显示“已复制”。

### 状态

- 初次加载显示“读取中…”。
- 读取失败显示错误与重试。
- 操作失败显示错误，已有数据保留。

## 侧栏触发

- 折叠（rail）时只显示图标；展开时图标旁显示 `MCP`。
- 悬停有底色，点击打开弹窗。
- 弹窗遮罩点击关闭；`Esc` 或 `×` 关闭。

## 授权

- 点击“授权”时同步打开空白标签页，拿到授权地址后导航；导航失败或被拦截时把地址显示在面板里。
- 回调完成后关闭临时回环监听；面板不轮询，用户点“重试”或再次打开时读取新状态。

## 配置页

- `view = 'summary'`：返回一行描述。
- `view = 'page'`：内联渲染共享面板，不显示遮罩与关闭按钮。
- 配置页不依赖宿主配置表单；所有写入走插件自己的路由。
