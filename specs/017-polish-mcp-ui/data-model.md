# Data Model: MCP 管理界面视觉优化

配置数据与路由数据保持现状。本功能只增加界面状态。

| 状态 | 字段 | 规则 |
| --- | --- | --- |
| 编辑状态 | `mode`、`values`、`originalName` | `create` 使用空表单；`edit` 使用所选服务器定义；名称编辑规则保持现状 |
| 删除状态 | `row` | 确认前保留列表；取消后焦点返回删除按钮 |
| 忙态 | `key` | `form` 对应保存；服务器名对应该行操作；`reload` 对应刷新 |
| 校验状态 | `errorKey` | 映射到名称、简介、地址、请求头、命令或回调地址字段 |
| 反馈状态 | `loadError`、`actionError`、`authUrl` | 加载失败可重试；操作失败使用警报语义；授权链接可换行 |

## 界面状态转换

1. 列表 → 新增/编辑 → 列表：保存成功或取消后关闭表单。
2. 列表 → 删除确认 → 列表：取消保留定义；确认成功后移除对应行。
3. 空闲 → 操作中 → 空闲：操作期间禁用对应控件并保留反馈。
4. 无错误 → 校验错误 → 无错误：提交时定位字段；修改字段后清除该错误。

主题由宿主管理，插件只消费当前 token。
